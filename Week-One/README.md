## 🛠️ Concepts Covered

1. **Output Statements:**
   - Rendering HTML tags using `echo` and `print`.
   - Passing multiple comma-separated arguments to `echo`.
   - Understanding limitations: `print` and `echo()` with parentheses do not accept multiple comma-separated arguments.

2. **Variable Interpolation:**
   - Declaring PHP variables (`$Fullname`).
   - Dynamically evaluating variables within double quotes.

3. **String Manipulation:**
   - Measuring character counts (including whitespace) using `strlen()`.
   - Counting total words within a string using `str_word_count()`.
